# Skill - Update Module README

Use this when a module's purpose, public API, local run command, or ownership boundary changes.

## Steps

1. Keep the README under 100 lines.
2. Summarise purpose, public API, dependencies, and local run/test commands.
3. Link deeper explanation to `docs/` instead of expanding the README.
4. Avoid copied source-code snippets.

## Done condition

- The README is short, current, and linked from the docs index if needed.
